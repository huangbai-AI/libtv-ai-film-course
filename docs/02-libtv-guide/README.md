#### 脚本节点 🎬

##### 🚩脚本功能全新升级

- **功能概述：从“基础脚本工具”升级到“分镜故事板脚本工具”。**

  - 新版脚本不只是把剧本拆成表格，而是把剧本拆解、剧本资产管理、分镜头调整、提示词合成、批量生图、批量生视频串成一条完整流程。
  - 适合流水漫、AI 短剧、动画短片、故事分镜等内容创作场景，可以更快完成：剧本拆解 → 角色/场景/道具资产提取 → 分镜脚本调整 → 批量生成分镜图 → 批量生成视频片段。



- 对比脚本旧版 解决的问题

针对收集的用户问题，新版脚本方案围绕四个关键词展开：**资产化、可编辑、可批量、灵活修改**

- **资产化**：将脚本从“纯文本表格”升级为“内容 + 资产”结构，风格、角色、场景、道具等资产与脚本绑定并可被提示词引用；
- **可编辑**：脚本的每一行、每一个字段、每一个资产都可以被用户修改，修改后能同步更新对应的提示词；脚本中的分镜支持新增、删除、调整顺序。
- **可批量**：用户可批量执行分镜图和分镜视频的生成。可自由选择生成范围（单个/部分/全部）、生成类型（批量生图、批量生视频）、以及批量执行的模型类型。
- **灵活修改：**新版脚本可以在批量生成前直接补充和调整，用户可在真正批量生图、生视频前，把角色、场景、提示词、参考图都修改补充到比较稳的状态，再进入生产。



- 三、使用方式功能介绍

  - **第 1 步：添加脚本节点**
  
    - **可通过两种方式**添加脚本节点：
    
      - 第一种，双击画布，或者打开底部的 “+”，选择「脚本 new」。
      - 第二种，先把剧本文本输入到一个文本节点里，再从文本节点拉出一条线，选择「脚本 new」。
    - 脚本节点的**前置输入**可以是一段**剧本文本**，也可以同时接入一些**参考图**，比如角色图、场景图、风格图等。
    
      - 如果只是想快速拆分镜，输入剧本文本就可以开始。
      - 如果希望后续生成的角色、画风、场景更稳定，建议在一开始就把关键参考图接进去，这样脚本节点在拆解时也可以更好地理解整体风格和角色设定。

- **第 2 步：开始生成**

将文本、图片节点与脚本节点连接后**，**或者直接在脚本节点的生成器输入框内输入剧本内容，选择合适的脚本拆解模型，**点击生成。**

- **模型的选择**：推荐优先选择CVLM5.5 或 GVLM 3.1 
- 生成后，脚本节点会自动完成几件事：

  -  把剧本文本拆成结构化 shot； 
  -  提取关键角色、场景、道具； 
  -  整理每个 shot 对应的画面信息； 
  -  为后续生图、生视频准备基础提示词。 

这一步相当于先把一段完整剧本拆成一份可编辑的分镜故事板。

![图片展示了LibTV脚本节点的使用界面。画面中有一个黑色背景的编辑区域，左侧有两张人物图片，中间有“根据剧本内容生成脚本”的提示。右侧有一个黑色方块，上方有红色箭头指向，标注“1. 将文本、图片节点与脚本节点相连”。下方有一个蓝色按钮，旁边也有红色箭头指向，标注“2. 点击生成”。该图片与文档中“编辑脚本节点”步骤相关，直观呈现了脚本节点生成后，将文本、图片节点与脚本节点相连及点击生成的操作指引。](./assets/OiFXb0NIsou5DpxvIGAcHZZInjc.png)





- **第 3 步：编辑脚本节点**

**这一步是后续生成是否准确的关键。**

脚本节点生成出来后，**不建议直接批量生图/视频**。更好的方式是先检查 shot 信息，管理好角色、场景、道具等资产，再进入后面的批量生成。

因为后续所有分镜图和视频片段，都会基于这里的信息继续生成。如果这里的角色描述不准、场景不清楚、镜头动作太弱，后面批量生成就会把这些问题放大。

- 第 5 步：批量生分镜图

  1. 等上一步镜头资产和最终提示词信息确认完毕之后，就可以选择批量生成分镜或者是批量生成视频了。
  2. 选择对应的镜头和对应的模型后，点击【确认并创建生成器组】，会在画布上创建一组生成器组。
  3. 注意：这里面不是空的生成器，这是一个将资产连线、脚本中的提示词、对应选择的生成器参数（模型、尺寸、分辨率等）都带过来的生成器。**点击选中对应的生成器即可查看。**
  4. 在这一步，用户可以自主补充更多的参考图信息，调整单独分镜的生成器参数，微调提示词信息等。
  5. 若**解组不会让生成器中的信息消失，**这是一个普通的组。
  6. 信息的流动是从脚本到分镜组的，如果在生成器内修改了信息，是**不会向上传递**给上游的脚本传递的。



对于短剧、漫剧、动画短片来说，这条链路可以减少很多重复操作：不用每个镜头都手动复制提示词，也不用在多个节点之间来回找角色和场景信息。

四、核心亮点

亮点 1：自动生成 角色、场景、道具，一致性调用

过去 AI 生成的脚本是"一锤子买卖"——不满意只能重新生成。现在不一样：

- 脚本里的**角色、场景、道具**都被拆成独立“资产”，可以单独修改、替换、复用
- 改一处，自动同步到所有相关画面
- **角色、风格、场景、道具**等在每个分镜里**保持一致，**不会“换个镜头换张脸”

亮点 3：先精细调整再批量，结果更可控

- 新版脚本不是直接让用户“一键到底”，而是在批量生成前留了一个检查和修正环节。
- 用户可以先看脚本拆得是否正确，角色提取得是否准确，场景有没有漏，提示词是否完整。
- 发现问题可以直接在脚本节点里修：

  -  缺角色/场景/道具图，可随时补充和添加； 
  -  镜头不顺，直接调整顺序； 
  -  分镜少了，新增 shot； 
  -  分镜多了，删除 shot； 
  -  风格不对，可在生成时加风格图或风格词进行修改。 
- 修完之后再批量生成，会比直接一键生成更可控。
- 整体逻辑更符合创作者实际工作方式：先出草稿，再人工调整，最后批量生产。



亮点 4：一个故事，从文字到成片，全程不用跳出平台

- 输入剧本 / 想法 / 参考图  → 自动生成结构化分镜脚本
- 一键**批量生成**所有分镜图、所有视频片段
- 将生成的视频片段合成为完整视频

亮点 5：更适合短剧、漫剧、AI 影视的批量生产

新版脚本不是只服务单张图或视频片段，而是更适合一整段故事的生产。

尤其是短剧和漫剧，经常会有这些需求：

-  一集里有大量重复角色； 
-  同一个场景会反复出现； 
-  需要快速拆分镜； 
-  需要批量生成素材； 
-  需要先测试几条，再批量跑全量； 
-  需要在成本和质量之间做控制。 

新版脚本可以把这些重复性的内容资产化，把每个镜头的生产变成可管理、可批量的流程。

它不是完全替代创作者判断，而是把创作者从大量重复整理提示词、复制角色信息、逐条生成的工作里解放出来。



五、创作者测评


> **提示**
>
新版脚本更适合的场景是：
1. AI影视/动画短片的灵感泛化、资产拆解、分镜生成
2. 短剧漫剧的剧集单集资产拆解、素材生产  
**一些局限**：
1. 无法做到精品短片一键直出，导演思维、时长的判断、镜头与镜头的衔接还是会有瑕疵。
2. 针对TVC场景的产品一致性会有不稳定的情况。



1. **新版脚本比较适合的场景主要有两类。**

   1. AI 影视 / 动画短片
   
      1. 适合做灵感泛化、剧本拆解、资产整理和分镜生成。
      2. 如果只是有一个故事想法，可以先让脚本节点拆成分镜，再看每个 shot 是否合理。
      3. 如果已经有比较完整的剧本，也可以直接用它来提取角色、场景、道具，快速生成一版故事板。
      4. 对早期创意验证来说，这个流程会比较高效。
   2. 短剧 / 漫剧单集素材生产
   
      1. 短剧和漫剧更依赖批量生产，一集里面经常有几十个镜头，而且角色和场景会反复出现。
      2. 新版脚本在这种场景下比较有优势：
      
         1. 可以快速拆单集分镜； 
         2. 可以统一管理角色和场景； 
         3. 可以批量生成分镜图； 
         4. 可以继续批量生成视频； 
         5. 可以先局部测试，再批量跑全量。 
      3. 对于流水线生产来说，它能减少很多重复操作。



1. **当前还存在的边界**

   1. 新版脚本目前还不是“精品短片一键直出”。
   
      1. 导演思维、镜头节奏、时长判断、镜头与镜头之间的衔接，还是需要人工介入。
      2. 尤其是精品 TVC 这类对产品一致性、镜头设计、品牌质感要求特别高的场景，当前生成稳定性还会有一些不确定性。
   2. 但整体来看，相比旧版，V2 的生产逻辑更完整，生成链路也更顺。对于需要快速拆剧本、搭故事板、批量出素材的创作者来说，新版脚本会比旧版更实用。

#### 常用节点操作 





选中某个节点后，点击右键可以对当前节点进行复制、复用、删除、创建资产等操作

- **创建资产**点击后对当前节点资源**进行命名、分类并保存为「资产」**；之后可以在画布左侧栏[「我的资产」](https://liblibai.feishu.cn/wiki/Loxfw6XHziYRk0kKzdjcFfp9nhb?contentTheme=DARK&last_doc_message_id=7610813486005177522&preview_comment_id=7610814670785481684&sourceType=feed&theme=light#share-UAMgdhEQkoViEXxM6b7cWxjanae)中随时查看、调用
- **复制&粘贴**通过 「Ctrl/Cmd+C」 「Ctrl/Cmd+V」 快速复制使用单个节点，**不保留**节点已有的连线信息
- **副本**快速复用当前节点，**保留**节点已有的连线信息当需要基于同一组参考素材生成多个不同结果时，使用副本功能可以一次性产出多个版本，不用手动重复连线配置
- **删除**支持通过 Delete 键快速删除当前节点，可通过 Command+Z 撤销删除操作

#### **2.2.1 全景720°🔥**


> **提示**
>
**使用须知：**
**1️⃣** AI 在生成**空旷的、无明确建筑、物体、空间做为参考的户外场景**（如草原、沙漠、大海）时，会存在全景特征不明显的问题。
**2️⃣ AI 生成存在随机性** 
① 偶然会出现全景图特征不明显的情况，一般再生成1-2次就能解决；
② 接缝无法无痕闭合、空间轻微扭曲等问题无法完全避免，但对图像/视频参考生成来说影响不大；
③ 可在截图后，考虑用 LibNavo 模型进行二次修复处理。
3️⃣ 对于Midjourney**高度个性化的风格特征**，风格一致性无法100%保持一致

**「创建运动」---操作演示（适合想让角色在 3D 场景中按指定路线移动）**

操作路径：

1. 用户在左侧对象树选中角色
2. 右侧出现「创建运动」入口
3. 点击后，系统自动生成一条默认运动路径
4. 用户可以选择直线、圆形、矩形等路径模板
5. 用户点击路径上的某一点，可以调整左右位置 X、前后位置 Y、高度 Z
6. 调整后，时间轴自动记录对应关键帧。
7. 点击播放后，角色沿路径运动

**适合场景**：

- 角色从门口走到房间中间。
- 角色绕商品或道具走一圈。
- 角色走上台阶、走下坡、穿过场景。
- 短剧人物走位、漫剧角色调度、电商广告人物展示

2. 右侧点击「跟随对象和跟随视角」
3. 用户只需要调整跟随距离、摄像机高度、拍摄角度、镜头范围。
4. 点击播放后，角色沿自己的路径运动，摄像机会保持距离和高度跟随拍摄。

这里需要特别注意：

1. 角色运动轨迹和摄像机运镜轨迹不是同一条线。
2. 角色路径可以贴地，摄像机不能直接吃角色的贴地路径。
3. 一键跟随的本质是“打成镜头组”，由系统自动维护摄像机和角色之间的距离、高度和注视关系。

适合场景：

1. 第三人称跟拍角色走路。
2. 短剧角色在房间里移动，镜头跟随拍摄。
3. 虚拟人介绍商品，镜头始终跟住人物。
4. 角色边走边讲解场景或道具。

**运镜控制使用小技巧：**

1. **Kling 3.0** 对「镜头左右移」提示的相应响应不准，对左右上下摇动偶尔不准确（已反馈给可灵官方，等待反馈）。**这种情况可以通过切换其他模型或者方式处理**
2. 不同的视角有不同的应用场景**，如果分镜应用不当，会导致失效的情况。**

> 比如「高空航拍」运镜会和画面中的「近距离、特写」等描述发生冲突

1. 另外为了适应不同的模型和场景**，预设提示词会显得比较简单和宽泛**，因此：

   1. 不同模型对相同预设的响应情况不同，属于正常现象
   2. 当画面主体较多、画面内容复杂、或者**主体本身有大幅度动作时，运镜效果很容易受到干扰**（可灵3.0的表现尤为明显）

   - **解决方案：**
   
     - 在运镜预设之外，额外添加镜头与主体、环境的关系描述
     - 若提示中涉及多种物体动作或运镜，**建议用「首先、然后、最后」等词语**来有秩序地描述物体动作和运镜的关系，模型处理效果会更好
