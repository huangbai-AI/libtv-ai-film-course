## 需要的案例

以下案例待提供

| **案例名称** | **数量** | **具体要求** | **交付内容** |
|-|-|-|-|
| 故事板正面案例 | 1 个 | 将一段 10—15 秒多人对峙剧情拆成 4—6 个连续分镜；每个分镜包含人物动作、景别、机位和衔接信息，并能批量生成分镜图。 | 原始剧情；完整故事板；分镜提示词；4—6 张分镜图；关键操作录屏。 |
| 故事板反面案例 | 1 个 | 使用模糊故事梗概生成故事板，保留镜头重复、动作跳跃或衔接不清的问题，用于说明信息不足的结果。 | 原始输入；问题故事板；问题标注图；简短问题说明。 |
| 3D 导演台正面案例 | 1 个 | 搭建三人对峙场景，控制角色、道具和站位；设置全景、越肩和低机位三个镜头，并将截图用于最终画面生成。 | 场景素材；导演台工程；3 张机位截图；最终画面；关键操作录屏。 |
| 3D 导演台反面案例 | 1 个 | 同一复杂场景只使用文字描述，不提供空间参考，展示人物朝向错误、位置互换或镜头关系混乱的问题。 | 原始提示词；错误画面；问题标注图；与正面案例的对比图。 |
| 人像调节正面案例 | 1 个 | 在多人画面中选择一名目标人物，先优化皮肤质感，再调整表情；其他人物、身份特征和原图构图保持不变。 | 原图；质感调整图；情绪调整图；三阶段对比图；关键操作录屏。 |
| 人像调节反面案例 | 1 个 | 分别展示质感参数过强和表情调整幅度过大的结果，能够清楚看出皮肤纹理失真、五官变化或情绪不自然。 | 2 张问题图；问题标注图；与正确结果的对比图。 |
