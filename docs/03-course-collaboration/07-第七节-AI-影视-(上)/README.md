# 第七节：AI 影视 （上）


> **提示**
>
**引入｜这节课会讲什么**
本节讲解 AI 短剧中剧本拆解、角色与场景统一、视频生成、配音和剪辑的制作流程。
- **核心内容：**AI 短剧的剧本导入与分镜拆解、角色场景资产统一、批量视频生成、配音音效和剪辑导出。
- **学完你会：**完成一段人物稳定、叙事连贯、声音完整的 AI 短剧片段。
