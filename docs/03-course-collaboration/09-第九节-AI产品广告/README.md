# 第九节：AI产品广告


> **提示**
>
**引入｜这节课会讲什么**
本节以产品广告为例，讲解从素材准备、脚本和分镜到生成、配乐和剪辑的制作过程。
- **核心内容：**产品资产精修、创意脚本、分镜与关键帧、视频生成、配乐剪辑及产品一致性控制。
- **学完你会：**把一个产品卖点转化为完整广告工作流，独立完成一支 AI 产品广告。
