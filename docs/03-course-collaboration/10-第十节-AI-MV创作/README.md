# 第十节：AI MV创作


> **提示**
>
**引入｜这节课会讲什么**
本节讲解 AI MV 的音乐分析、视觉设计、角色与场景资产、镜头生成和后期调整。
- **核心内容：**音乐与多模态参考、角色资产、脚本故事板、导演台调度、视频生成和细节精修。
- **学完你会：**让声音和画面形成统一叙事，完成一支角色与风格保持一致的 AI MV。
