# 第十一节：AI 知识类动画


> **提示**
>
**这节课会讲什么**
把一段知识讲解内容拆成画面、图表、文字和动画，完成一条适用于科普、财经或科技内容的讲解短片。
**课程成果：**完成一条 15—20 秒知识讲解动画。
