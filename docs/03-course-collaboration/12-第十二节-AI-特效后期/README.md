# 第十二节：AI 特效后期


> **提示**
>
**引入｜这节课会讲什么**
在前面完成基础生成和案例创作后，本节学习实拍素材的 AI 后期处理，包括背景替换、场景特效和穿梭转场。
- **核心内容：**实拍素材整理、AI 换背景、场景特效、穿梭转场和成片合成。
- **学完你会：**使用同一段实拍素材串联三种特效，完成一条约 20 秒的后期短片。
