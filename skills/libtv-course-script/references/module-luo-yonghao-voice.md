# 模块：罗永浩课程表达层

## 定位

本模块只用于 LibTV 课程口播的最后一轮表达润色。目标是借鉴成熟公开表达中的节奏、论证和现场感，不是复制罗永浩本人，也不是收集口头禅。

不能修改阶段、大纲、内容、产品事实、案例、数据、操作步骤和课程观点；不能编造讲师经历、立场或个人评价。

## 可使用的表达特征

### 1. 充分准备后的聊天感

- 内容逻辑和材料准备充分，表面呈现仍像在与人交流。
- 允许自然停顿、补充和轻微自我修正，不写成朗诵腔。
- 先照顾听众的疑问，再给结论，不摆出训导姿态。

### 2. 先把话说准确

- 对容易被误解的概念先限定范围，再给判断。
- 区分“事实、经验、建议、个人取舍”，避免把推荐说成唯一答案。
- 必要时承认限制、随机性和成本，可信度高于夸张承诺。

### 3. 结论、理由、例子连续推进

- 先给明确结论。
- 紧接着解释为什么。
- 用一个具体场景、对比或可见结果落地。
- 最后回到学员此刻该做什么。

### 4. 短句与长句交替

- 关键结论使用短句并独立成行。
- 解释可以稍长，但每句只承担一个主要动作或判断。
- 通过停顿、递进和回收形成节奏，不靠连续感叹号制造重音。

### 5. 预判质疑

- 在学员可能问“为什么不用另一种方法”“是不是模型不行”“能不能一次拉满”之前主动回应。
- 回应先承认疑问合理，再给判断依据和适用边界。
- 不把假想听众写得愚蠢，也不制造无意义对立。

### 6. 克制的幽默和自嘲

- 幽默用于缓解认知压力、承认现实麻烦或修复现场小失误。
- 一段教学最多放一个轻笑点，不能盖过知识点。
- 不使用攻击性笑话、低俗词、网络热梗或与课程无关的段子。

### 7. 用画面和演示控制节奏

- 重要结论之后留出结果画面、前后对比或参数特写。
- 画面负责证明，口播负责解释判断。
- 需要说服学员时优先拿出示例、数据、版本或实际演示，不只靠语气。

## 默认强度

默认使用“中低强度”：

- 保留清楚结论、聊天感、限定语、对比和轻微幽默。
- 不主动添加口头禅、夸张人设、自我神话、强攻击性或密集包袱。
- 用户要求更强风格时，只提高节奏、对比和现场感，仍不复制具体表达。

## 润色步骤

1. 先确认基础稿事实完整、画面可执行。
2. 删除书面套话、重复定义和无信息承接句。
3. 把关键结论提前，并补足理由、边界或例子。
4. 调整句长和停顿，让每句可以自然朗读并独占一行。
5. 只在认知负担高的位置加入少量幽默或自我修正。
6. 与基准稿做差异检查，确保只改变表达，没有改变事实和观点。

## 禁止项

- 复制或近改公开演讲、访谈和课程旧稿中的原句。
- 堆叠“说实话”“你想想”“我跟你讲”等表面口头禅。
- 机械重复“不是……而是……”制造假反转。
- 凭空添加罗永浩的个人经历、习惯、评价、承诺或品牌背书。
- 为了笑点贬低新手、同行、平台、模型或失败结果。
- 把模型概率、经验建议和当前观察说成绝对规律。

## 试听检查

- 像一个准备充分的人在现场解释，还是像宣传稿？
- 关键结论是否清楚，理由是否紧跟？
- 幽默是否服务于理解，而不是抢戏？
- 是否有无法配画面、无法自然停顿的超长句？
- 去掉讲师名字后，仍然是一篇准确、独立、属于 LibTV 的课程稿吗？
